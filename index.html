중복 · 유사 이미지 검색

DNS·hosts 설정과 노출 가능성이 있는 키를 점검합니다. 사용 기록 정리는 선택한 항목에만 적용합니다.

시스템 경로와 핵심 프로세스를 보호하고, 변경이 필요한 작업은 적용 전에 대상을 다시 확인할 수 있게 합니다.

시스템 핵심 보호 목록

csrss, lsass, explorer, TrustedInstaller 등 핵심 프로세스·서비스는 종료나 변경 대상에서 제외합니다.

위험 경로 차단

Windows, Program Files, EFI 등 보호 폴더와 UNC 네트워크 경로는 삭제 대상에서 자동 제외됩니다.

직접 설치판의 레지스트리 정리 전 복원 지점 생성을 안내합니다. 위험도가 높은 항목은 기본으로 선택하지 않습니다.

FAQ

자주 묻는 질문.

정말 무료인가요? 광고나 결제가 있나요?
현재 제공되는 기능은 무료이며 광고가 없습니다. Store판과 직접 설치판의 기능 구성은 다릅니다. 이용 조건은 라이선스 페이지에서 확인할 수 있습니다.
레지스트리를 건드려도 안전한가요?
레지스트리 정리는 직접 설치판에서 제공합니다. 정리 후보와 위험도를 먼저 확인하고, 작업 전 복원 지점을 만들어 두는 편이 좋습니다. 위험도가 높은 항목은 기본으로 선택하지 않습니다.
Store판과 직접 설치판은 무엇이 다른가요?
Store판은 Microsoft Store에서 설치하고 업데이트합니다. 레지스트리·서비스처럼 시스템 설정을 바꾸는 도구는 직접 설치판에서 제공합니다.
Mac이나 Linux도 지원하나요?
현재는 Windows 10(1809+) 및 Windows 11만 지원합니다. 기능 대부분이 Windows API와 레지스트리에 의존하므로 다른 OS 지원 계획은 없습니다.
업데이트는 어떻게 받나요?
Microsoft Store 설치본은 Store에서 업데이트됩니다. GitHub 직접 다운로드 빌드는 공식 다운로드 버튼에서 최신 설치 파일을 받거나 앱 안에서 새 버전을 확인해 설치할 수 있습니다.
오픈소스인가요?
앱 소스코드는 공개되어 있지 않습니다. 이용 조건과 변경 기록은 공개되어 있습니다.
