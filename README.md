# PC 바른 공식 사이트

PC 바른은 Windows 10/11용 무료·무광고 PC 정리 도구입니다. 임시 파일과 캐시,
중복 파일, 비슷한 사진, 빈 폴더를 검사하고 삭제할 대상을 직접 고를 수 있습니다.

- [공식 사이트](https://teemozipsa.github.io/PCBareun-site/)
- [Microsoft Store에서 설치](https://apps.microsoft.com/detail/9NJ36D4PLJ8H)
- [지원·문의](https://teemozipsa.github.io/PCBareun-site/support.html)
- [개인정보처리방침](https://teemozipsa.github.io/PCBareun-site/privacy.html)

Microsoft Store가 설치와 업데이트를 관리합니다. 앱은 MSIX 패키지 안에서
동작할 때 결과를 보장할 수 없는 시스템 변경 도구를 표시하지 않습니다.

이 저장소에는 공개 웹사이트와 과거 릴리스 자료가 들어 있습니다. PC 바른
앱의 현재 배포는 기존 Microsoft Store 상품 `SeonkyuIM.PC`를 사용합니다.
